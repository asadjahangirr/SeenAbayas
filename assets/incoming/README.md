# Incoming brand assets

Add future product photography here before assigning it to a design. Do not rename or overwrite existing originals.

Originals are grouped under `assets/source/products/design-XX`. IDs and visual captions are provisional photo groupings, not confirmed product names or sellable variants. Update `assets/manifest.json` after inspecting new photos, then run `npm run prepare:media` to create optimized public copies and the application media index.

Videos remain under `assets/source/videos/unassigned` until their design associations are confirmed. Exact duplicate source photos are preserved under `assets/source/duplicates`.
